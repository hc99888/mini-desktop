# 迷你桌面

一个极简单文件 PWA 桌面，用于集中管理自己部署的各类小应用。
手机 / 电脑打开即用，可"添加到主屏幕"像 App 一样启动，支持离线。

---

## 🚀 首次部署

1. 把上面所有文件上传到仓库根目录
2. 确保 `apps/` 下每个应用目录都有对应的图标文件（`icon.webp` / `logo.png` 等）
3. 用 GitHub Pages / 任意静态托管打开 `index.html`
4. 手机浏览器打开 → 菜单 → **"添加到主屏幕"**

---

1. 把应用文件夹放进 `apps/`（例如 `apps/新应用/`）
