
# 迷你桌面

一个极简单文件 PWA 桌面，用于集中管理自己部署的各类小应用。
手机 / 电脑打开即用，可"添加到主屏幕"像 App 一样启动，支持离线。

---

## 📁 目录结构
├── index.html ← ★ 主体（配置 / 样式 / 逻辑全内联，发版只改这里）

├── sw.js ← Service Worker（极少改动）

├── manifest.json ← PWA 清单（装到桌面用，极少改动）

├── icon-192.png ← PWA 图标（必需）

├── icon-512.png ← PWA 图标（必需）

└── apps/ ← 你的各个小应用，原样保留

├── 订阅推送/

├── 仓库资源/

├── 测试00/

└── ...
---

## 🚀 首次部署

1. 把上面所有文件上传到仓库根目录
2. 确保 `apps/` 下每个应用目录都有对应的图标文件（`icon.webp` / `logo.png` 等）
3. 用 GitHub Pages / 任意静态托管打开 `index.html`
4. 手机浏览器打开 → 菜单 → **"添加到主屏幕"**

---

## ➕ 添加一个新应用

1. 把应用文件夹放进 `apps/`（例如 `apps/新应用/`）
2. 准备一个图标，例如 `apps/新应用/logo.png`
3. 打开 `index.html`，在 `APPS` 数组末尾加一行：

   ```js
   { "name": "新应用", "icon": "apps/新应用/logo.png", "url": "apps/新应用/" },
